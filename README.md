# Tabble

**My very own new tab page!** Has a search bar, a news feed, shortcuts, and more!

Tabble is a custom, new-tab homepage made with plain HTML, CSS, and JavaScript. It gives you a simple page with quick access to websites, a clock, the current date, search, news, and more!.

## Features

* **Search bar** — Search the web from Tabble.
* **Multiple search engines** — Choose between:
  
  * Google
  * Bing
  * Yahoo
  * DuckDuckGo
* **Live clock** — Displays the current time.
* **Current date** — Shows today's date.
* **News feed** — Fetches recent news and displays the latest info.
* **Quick shortcuts** — Quickly open useful sites.

## Shortcuts

Tabble currently includes shortcuts to:

* Google
* YouTube
* Reddit
* Wikipedia
* GitHub
* Stardance
* Hack Club

## Built With

* **HTML**
* **CSS**
* **JavaScript**
* **Webz.io** — News API
* **CORS Proxy** — Webz.io needs CORS headers


## Files

### `index.html`

Contains the main page, including the search engine selector, search bar, clock, date, shortcuts, and news.

### `style.css`

Chooses the appearance of Tabble, including the background, fonts, colors, borders, and layout.

### `script.js`

Handles the moving parts of Tabble, including the live clock, date, news fetching, searching, and random greetings.

## Running Tabble

Tabble is a static website, so you can run it without installing anything.

### Option 1 — Open it yourseld

Download/clone the project and open:

```text
index.html
```
And Tabble will be there!

### Option 2 — Use a local web server

Tabble is hosted at tabble-nine.vercel.app
